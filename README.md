# ESP32-WROOM-32 + YOLO: Sistema de Control y Visión por Computadora

Este repositorio integra dos proyectos complementarios en una sola plataforma:

1. **Control de LEDs por pulsadores** utilizando las capacidades de GPIO de la ESP32-WROOM-32, demostrando el manejo de entradas/salidas digitales con interrupciones.

2. **Detección de vehículos (carros y motos)** mediante un modelo YOLO (You Only Look Once) entrenado previamente, ejecutado en un entorno virtual para demostrar aplicaciones de visión por computadora en tiempo real.

Ambos proyectos comparten el mismo ecosistema de desarrollo, mostrando la versatilidad de la ESP32 para aplicaciones embebidas y de inteligencia artificial en el borde.
